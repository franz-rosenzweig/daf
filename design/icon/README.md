# The Daf icon (draft)

A matcha scroll on a white macOS tile, tilted right, the top rolled one way and the bottom the other.
`python3 make_icon.py` writes `daf-icon.svg`; `../../.venv/bin/python render.py daf-icon.svg daf-icon-1024.png` renders it in the
headless Chrome container. This was the first draft; the icon in use came out of the rounds in r1 to r4 and
is in `final/`, made by `export.py`.
